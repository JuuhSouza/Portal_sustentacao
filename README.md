Rodar o Código:

## Extensao Edge

A extensao fica em `edge-extension/` e injeta o painel de guia de chamados quando o usuario clica no icone.

Instalacao (Edge):
1. Abra `edge://extensions`.
2. Ative **Developer mode**.
3. Clique em **Load unpacked**.
4. Selecione a pasta `edge-extension`.
