# Guia de Chamados - Extensao Edge

Extensao simples que injeta um painel de guia de chamados sobre qualquer site quando o usuario clica no icone da extensao.

## Instalacao (Edge)

1. Abra `edge://extensions`.
2. Ative **Developer mode**.
3. Clique em **Load unpacked**.
4. Selecione a pasta `edge-extension`.

## Uso

- Abra qualquer site.
- Clique no icone da extensao para mostrar/ocultar o painel.

## Estrutura

- `edge-extension/manifest.json`
- `edge-extension/background.js`
- `edge-extension/content.js`
